# 多语言规范

Duolo 的每个面向用户的功能都必须支持多语言。新增或修改界面时，按本文的规则同时更新所有语言。

## 支持的语言

| 代码 | 语言 | 代码 | 语言 |
|---|---|---|---|
| `en` | English（基准） | `fr` | Français |
| `zh-CN` | 简体中文 | `de` | Deutsch |
| `zh-TW` | 繁體中文 | `pt-BR` | Português (Brasil) |
| `ja` | 日本語 | `ru` | Русский |
| `ko` | 한국어 | `it` | Italiano |
| `es` | Español | `tr` | Türkçe |
| `vi` | Tiếng Việt | `id` | Bahasa Indonesia |

默认跟随系统语言（`~/.duolo/settings.json` 里 `language = "auto"`），用户可以在侧边栏左下角的地球图标里切换。
系统语言不在列表里时使用英文。

## 文案放在哪里

| 位置 | 内容 |
|---|---|
| `app/src/i18n/locales/en.ts` | **基准**。所有键先在这里定义。 |
| `app/src/i18n/locales/<code>.ts` | 其他语言，类型是 `Messages`，必须提供和英文完全相同的键。 |
| `app/src/i18n/index.tsx` | 语言列表 `LOCALES`、系统语言识别、`t()`、错误翻译 `errorMessage()`。 |
| `crates/duolo-app/src/locale.rs` | 原生菜单的文案，以及审阅结论使用的语言名。 |
| `crates/duolo-app/Info.plist` | `CFBundleLocalizations`：向 macOS 声明支持的语言。 |
| `crates/duolo-core/src/error.rs` | 用户可处理的错误：错误码 + 参数，文案在语言包的 `error.*` 里。 |

## 规则

1. **界面上不写死文字。** 组件里的所有文字都用 `const t = useT(); t("key", { name })` 取。
   品牌名（Duolo、Claude、Codex、git）和快捷键符号除外。
2. **先写英文，再补齐所有语言。** 在 `en.ts` 加键后，TypeScript 会要求每个语言文件都加上同样的键；
   `pnpm build` 还会运行 `scripts/check-i18n.mjs`，检查每条译文的占位符（`{name}`）和英文一致。
3. **用占位符，不拼字符串。** 写 `t("sidebar.running", { count })`，不要写 `` `${count} ` + t("running") ``，
   不同语言的语序不同。
4. **后端不返回给用户看的句子。** 用户可能遇到并能处理的错误，在 `UserError` 里加一个变体（带 `code()` 和参数），
   在每个语言包里加 `error.<code>`；其他内部错误用 `anyhow`，英文描述，界面显示通用文案并附上详情。
   日志和命令行输出用英文。
5. **原生菜单**的文案在 `locale.rs` 的 `menu_text()` 里，每种语言一组；新增菜单项要补齐所有语言。
6. **发给 Agent 的提示词**用英文写，并说明回答语言：审阅提示词里的 `{language}` 会换成界面语言；
   语音整理要求"使用用户说话的语言"。
7. **语气**：简短、直接、说清楚怎么处理。中文用全角标点，按钮用动词开头（"关闭任务"）。
8. **终端界面（`duolo tui`）**暂时只有中文，不在本规范范围内；新功能以桌面应用为准。

## 新增一种语言

1. 复制 `app/src/i18n/locales/en.ts` 为 `<code>.ts`，类型改为 `Messages`，翻译全部条目。
2. 在 `app/src/i18n/index.tsx` 的 `LOCALES` 里登记（`name` 用该语言自己的写法）；
   如果系统语言标签需要特殊对应（例如 `zh-Hant` → `zh-TW`），在 `matchLocale()` 里处理。
3. 在 `crates/duolo-app/src/locale.rs` 的 `menu_text()` 和 `language_name()` 里加上这种语言。
4. 在 `crates/duolo-app/Info.plist` 的 `CFBundleLocalizations` 里加上语言代码。
5. 运行 `cd app && pnpm build` 和 `cargo test -p duolo-app`。
