隐私政策

生效日期：2026 年 11 月 27 日

本政策说明 Duolo 桌面应用、Duolo 手机应用和 duolo.io 上的 Duolo 服务（统称"Duolo"）会处理哪些信息、为什么处理。Duolo 由爱塔科技（杭州）有限公司（Aita Technology (Hangzhou) Co., Ltd.，下称"我们"）运营。

简要说明

  • Duolo 在你自己的电脑上运行编程 Agent。你的代码、Agent 会话和任务记录都留在你的电脑上。
  • Agent（例如 Claude Code、Codex）用你在各服务商的账号直接和服务商通信，不经过我们，适用各服务商的隐私政策。
  • 只有在你使用需要 Duolo 服务的功能时，我们才会收到数据：语音输入、登录、把手机连到电脑。
  • 我们不出售你的数据，不投放广告，不用你的数据训练模型。

我们收集什么、为什么

账号

登录时，我们保存你的邮箱地址，用来给你发一次性登录验证码。不登录也使用需要服务的功能时，应用会创建一个匿名身份，以便我们执行用量限制。我们为你的每台设备保存登录会话，包括建立会话时记录的 IP 地址和客户端标识，用于保障账号安全。

设备

对连到你账号的每台设备，我们保存它的名字、平台（例如 Mac、iOS）、端到端加密用的公钥；如果你允许通知，还有推送令牌。

手机和电脑之间的消息

手机和电脑配对后，它们之间的消息（任务列表、对话、指令）在离开设备前就已端到端加密，我们无法读取。我们负责转发；接收的设备不在线时，加密的消息最多保留 7 天，之后删除。

语音输入

使用语音输入时，你录下的声音经我们的服务器实时转给语音识别服务商火山引擎（字节跳动），同时附带当前任务里的提示词（例如文件名、函数名）和最近几句对话，以便准确识别技术名词。如果你让 Duolo 整理所说的话，识别出的文字和提示词还会发给大模型服务商。我们不保存声音和识别出的文字，只记录每个账号每天用了多少秒语音，用于每日限额。

检查更新

桌面应用会向 GitHub 查询 Duolo 和你安装的 Agent 有没有新版本。这些请求直接发给 GitHub，适用 GitHub 的隐私声明。

本网站

duolo.io 不使用 Cookie、统计分析或追踪工具。网站服务器保留常规访问日志（IP 地址、时间、访问的页面），用于安全和排查问题。

数据存放在哪里

Duolo 服务运行在阿里云位于美国的服务器上；语音由火山引擎处理。这些服务商只代表我们处理数据，用于提供服务。

保留多久

  • 账号和设备信息：直到你删除账号或解除该设备。
  • 转发中的加密消息：送达为止，最多 7 天。
  • 语音用量记录：最多 90 天。
  • 服务器访问日志：最多 60 天。

你的选择和权利

不登录、不用语音输入也可以使用桌面应用，这时没有任何个人数据会到我们这里。你可以随时从账号里解除某台设备。如需获取你的数据副本，或删除账号及全部相关数据，请按下面的方式联系我们，我们会在 30 天内处理。根据你所在地的法律（例如《个人信息保护法》、GDPR、CCPA），你可能还享有其他权利，也可以向当地的个人信息保护机构投诉。

儿童

Duolo 是开发者工具，不面向 13 岁以下（或你所在国家规定的最低年龄以下）的儿童，我们不会有意收集他们的数据。

变更

本政策如有变更，我们会更新上面的日期；重大变更会在应用里告知你。

联系我们

在 github.com/OtterMind/duolo/issues 新建一个 Issue。涉及个人数据的请求，请不要在 Issue 里贴出数据本身，只说明你的需求，我们会私下联系你核实并处理。
